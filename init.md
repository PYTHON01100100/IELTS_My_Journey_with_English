# Getting Started — How to Use This Repo

This is your personal workflow for practicing English grammar, paragraph writing, and presentation speaking on the way to IELTS.

## 1. Grammar Lessons — [`Grammers/`](./Grammers/)
- [`grammer.md`](./Grammers/grammer.md) is the **standard template**. Every tense/topic lesson copies this structure.
- [`present simple.md`](./Grammers/present%20simple.md) is the first worked example — study it, do its exercises, then move to the next tense by copying `grammer.md` into a new file.

## 2. Paragraph Writing — [`PARAGRAPHS/`](./PARAGRAPHS/)
Each topic gets its own folder with two files — see [`PARAGRAPHS/README.md`](./PARAGRAPHS/README.md) for the full convention:
1. Write `my-version.md` **by hand, no AI help**, ~255 words.
2. Have it corrected into `ai-corrected.md` — same ideas, rewritten to IELTS Writing Task 2 standard (255 words), with a "What changed" note explaining the fixes.
3. Review what changed before writing the next topic.

Start with [`PARAGRAPHS/climate change/`](./PARAGRAPHS/climate%20change/) as the worked example.

## 3. Presentation Training — [`presention training/`](./presention%20training/)
Same two-file convention, applied to 60-second spoken scripts instead of written paragraphs:
1. Write `my-version.md` by hand (aim for ~120-150 words / 60 seconds spoken).
2. Compare against `ai-corrected.md`, a polished reference script.
3. Record yourself reading your script out loud and time it.

Start with [`presention training/cloud computing/`](./presention%20training/cloud%20computing/).

## 4. Daily Routine
Pick one lane per session (grammar, paragraph, or presentation) rather than mixing all three — consistency beats intensity. See the suggested study plan in the main [`README.md`](./README.md).
