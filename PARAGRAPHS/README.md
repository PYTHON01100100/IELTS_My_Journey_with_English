# Paragraph Practice — Convention

Each topic gets its own folder containing two files:

```
PARAGRAPHS/<topic name>/
├── my-version.md        → written by hand, first draft, ~255 words, kept unedited
└── ai-corrected.md       → same ideas, corrected and rewritten to IELTS Writing Task 2 standard, 255 words
```

## Workflow
1. Pick a topic and write `my-version.md` by hand, no AI help. Aim for 255 words.
2. Ask AI to correct and upgrade it for IELTS band 7+ (Task Response, Coherence & Cohesion, Lexical Resource, Grammatical Range) into `ai-corrected.md`, keeping the same ideas and structure.
3. Add a short "What changed" section at the bottom of `ai-corrected.md` explaining the key fixes, so the lesson is visible on review.
